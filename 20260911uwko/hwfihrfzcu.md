# 百日咳偏方有哪些

> 更新时间：2026-09-11 (UTC+8)

百日咳属于常见的呼吸道传染病，主要是因为感染了百日咳杆菌引起的一种疾病。在我国的民间，流传着不少治疗百日咳的偏方，但并不是每一种治疗百日咳的偏方都有着不错的治疗效果。那么，比较有效果的百日咳偏方有哪些呢？

1、大蒜1 个、甘草未12 克、冰糖适量。大蒜捣烂，与甘草、冰糖加水煮汁，分3 次服。　　　　　　

2、芹菜500 克，盐、酒造量。芹菜洗净捣烂取汁，加盐、酒少许，隔水温势，早晚各服1 酒盅，连用数日。　

3、刀豆籽15 克、蜂蜜适量。刀豆籽水煎，去渣，加蜂蜜饮服，每日1 剂，连服5 天。　　　　

4、麻黄未1.5 克、面粉9 克、甜酒适量。上药共和匀制成饼状，外敷于患者背部肺俞穴，24 小时内敷2～3 次。　

5、白芝麻50 克、花生30 克、蜂蜜50 克。同放锅中加水煮汤服。每天1 次，连服3～5 天。　　　　

6、百部10 克、蜂蜜适量。百部煎汤20 毫升，加蜂蜜2 匙，顿服，每日2 次。此偏方不宜久服。

7、绿茶1 克、罗汉果20 克。罗汉果加水至300 毫升，煮沸5 分钟后加入绿茶，分3～5 次服，每日1 剂。　

8、绿茶1 克、淡竹叶25 克、橄榄15 克、红糖25 克。取水500 毫升，先煮后3 味至沸，3 分钟后加入绿茶即可，分4～5 次服，每日1 剂。

9、大蒜籽10 克。大蒜籽去皮后捣烂加凉开水50 毫升，浸半天。分3 次口服。

10、可以用一个梨，在准备适量的麻黄，把梨子切片，将麻黄适量的撒在梨子上面，然后再在锅里煮熟，可以喝里面的汤汁，也可以将麻黄去掉，吃里面的梨子，这些对于小儿止咳都是非常有帮助的。
