# 江大附院三伏贴火热进行中！

> 更新时间：2026-09-17 (UTC+8)

各位亲，请注意！江南大学附属医院（三院院区）三伏贴**7月26日**中伏贴即将开始了，后续贴敷日分别为**8月05日**、**8月15日**、**8月25日**，错过前几次贴的朋友，赶快来贴吧……

**贴敷疗法有哪些作用？**

       穴位贴敷疗法是通过药物敷于特定腧穴，通过皮肤的吸收和渗透发挥治疗作用，能够调整经络与脏腑功能，提高机体免疫力，增强机体的抗病能力，从而获得内病外治的疗效，免除打针吃药的痛苦，堪称绿色疗法。

**冬病夏治“三伏贴”意义**

     “冬病夏治”三伏贴是根据“春夏养阳”与“治未病”的中医理论，利用夏季气温高、人的机体阳气充沛、体表经络中气血旺盛、疾病发作缓解这样的有利时机，通过中医体质辨识后，在相应穴位上外贴药物来进行扶正培本治疗，使人体达到“正气存内, 邪不可干”的状态，以达到治疗、调养和预防疾病的目的。

**三伏贴主要治疗哪些疾病？**

     主要针对两周岁以上虚寒体质的人群，患有冬季容易发作或遇冷易加重的疾病。

**➤** **呼吸系统疾病：**慢性支气管炎、慢性阻塞性肺病、哮喘、过敏性鼻炎、慢性咽喉炎、体虚易感冒、反复呼吸道感染者。

**➤** **消化系统疾病：**脾胃虚寒性的慢性胃炎、消化性溃疡等引起的胃胀胃痛、胃肠功能紊乱及各种虚寒性的慢性腹泻。

**➤** **妇产科疾病：**虚寒性痛经、产后头痛、体虚腰痛。

**➤** **儿科疾病：**反复感冒、小儿哮喘、小儿夜啼、厌食、遗尿、流涎。

**➤** **骨科疾病：**寒性或者慢性的颈肩腰腿痛、骨性关节病（风湿性、类风湿）。

**➤** **其他：**体质虚弱者，常年四肢寒凉怕冷、免疫功能低下，阳虚性的阳萎、前列腺增生症、中老年人小便困难、尿频等。

**已错过前几次帖敷，今年还能贴吗？**

     一般说来只要在6月21至8月25这段时间，帖敷达到4次，就能有一定效果，但较贴敷6次的效果略差。所以，根据我们全国冬病夏治专项会议专家建议每年帖敷6次，不少于4次。小孩一般为纯阳之体，单纯阳虚较少见，以气虚易感风邪为主，故只需要帖敷4次即可。考虑到贴敷次数对疗效的影响，建议欲贴敷的朋友，尽早前来。

**除了三伏贴，有没有其他“冬病夏治”治疗方法？**

      冬病夏治的方法很多，比如：内服方法1、中药汤剂、颗粒剂2、中成药3、膏方4、药膳。外用方法 ：穴位敷贴、针刺、艾灸法、温针灸、穴位注射、推拿、拔火罐、脐疗、中药熏蒸等，而三伏贴只是其中的一种方法。所以未能贴敷或不适合贴敷的朋友，也可以至江大附院（三院区）针灸科选择其他治疗方法，一样可以为您的健康保驾护航！

**如果帖敷当天不能来帖，怎么办？**

     如果当天无法前来帖敷，建议在帖敷时间延后的2-3天的上午来帖，遇周日顺延。若女性朋友遇到生理期，可以在生理期3天后来帖或其中一次放到8月5日闰中伏那天。
