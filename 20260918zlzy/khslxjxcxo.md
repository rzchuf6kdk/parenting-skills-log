# 山东省临沂市妇幼保健院不孕不育检查项目及费用具体解析

一、不孕不育检查项目

1. 基础内分泌测定

基础内分泌测定是不孕不育检查的重要项目之一，通常在月经来潮的第2-5天清晨空腹抽血检查性激素六项及抗缪勒氏管激素(AMH)。这一检查能够了解女性的卵巢功能、黄体功能以及是否存在排卵障碍等问题。

2. 基础体温测定(BBT)

基础体温测定是一种简单而有效的自我监测方法，通过每日清晨在静息状态下测量体温并记录，可以初步判断女性的排卵日期及是否存在排卵功能障碍。

3. 子宫输卵管造影

子宫输卵管造影是评估女性输卵管通畅性的重要手段。临沂市妇幼保健院提供多种造影方法，如X线下造影、超声造影等，费用因检查方法和造影剂选择而异，大致在500元至2000元之间。

4. 免疫检查

免疫检查主要用于检测血液中是否存在抗精子抗体等免疫因素，这些因素可能导致精子凝集或失去活动力，从而影响受孕。

5. 婴方精液检查

不孕不育并非单一方的问题，因此婴方精液检查也是必不可少的。通过精液检查，可以了解精子的数量、活力、形态等指标，判断是否存在精液异常。
